# 🚀 NgDemo

NgDemo là dự án web admin được xây dựng bằng **Angular 19**, kết hợp với **TailwindCSS** và **PrimeNG** để tạo ra một hệ thống quản trị hiện đại, gọn gàng và dễ mở rộng.  
Ứng dụng hỗ trợ **Dark/Light mode** 🌙☀️ và **đa ngôn ngữ (i18n)** 🌍.

---

## ✨ Tính năng nổi bật
- 🔑 **Authentication**: Đăng nhập, đổi theme, đổi ngôn ngữ.
- 📦 **Quản lý sản phẩm**: Lọc theo giá, tồn kho, phân trang, sắp xếp nâng cao.
- 🛒 **Quản lý đơn hàng**.
- ⚙️ **Trang Cài đặt**: Theme & Layout, Product Preferences, Account & Security.
- 🌙 **Dark / Light mode**.
- 🌍 **Hỗ trợ đa ngôn ngữ** với **ngx-translate**.

---

## 🛠️ Yêu cầu môi trường
Trước khi bắt đầu, hãy chắc chắn bạn đã cài đặt:
- [Node.js >= 18](https://nodejs.org/)
- [Angular CLI ^19.2.15](https://angular.dev/tools/cli)
- Trình quản lý gói: **npm** hoặc **yarn**
